# Variable:
        "A variable is a container that is used to store any  type of data."

# Variable Declaration + Initialization:
        --> Syntax:
                let variable_name="value";

        Doesn't matter if u don't use semi-colon at the end cuz JavaScript uses a feature called Automatic Semicolon Insertion (ASI). 
        The JavaScript engine automatically inserts missing semicolons at the end of line breaks during parsing, making semicolons ** technically optional ** in most situations.

# Types of Variables in JavaScript:
        --> var:    Function-scoped varible     <-- var is avoided in modern JavaScript
        --> let:    Block-scoped variable
        --> const:  Block-scoped constant; cannot be re-assigned

# Hoisting:
        "In JavaScript, hoisting means declarations are processed 
        before the code runs."

        --> The important part is that var, let, const, and functions 
        behave differently.

        --> Hoisting is not visible in Practicle life but is present
        as an interview question.
