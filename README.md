# Git & GitHub Practice Repository 🚀

This repository contains my hands-on practice work for learning **Git, GitHub, and version control fundamentals**.

I created this repository while following the **Full Stack Development with MERN** course offered by **DigiSkills.pk**. The repository is used to practice Git commands, understand GitHub workflows, and maintain the exercises and changes performed during the course.

## 📚 About This Repository

The main purpose of this repository is to build a strong understanding of:

* Git fundamentals
* GitHub repositories
* Version control
* Commits and commit history
* Tracking file changes
* Working with branches
* Pushing and pulling changes
* Repository management
* Practical Git/GitHub workflow
* Full Stack Development learning exercises

## 🎯 Learning Objectives

Through this repository, I am practising how to:

1. Initialise and manage Git repositories
2. Track changes using Git
3. Stage files for commits
4. Create meaningful commits
5. Push local changes to GitHub
6. Pull changes from remote repositories
7. Understand Git branches
8. Work with GitHub as a remote repository
9. Maintain a clean development history
10. Use Git as part of a real development workflow
